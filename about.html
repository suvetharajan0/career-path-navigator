About This Project

Project Introduction

The Career Path Selection System is a college team project. Many students find it hard to choose a career after their studies. This website helps them explore different career fields by answering a short questionnaire.

Objectives

  • Help students think about their interests, skills and strengths.
  • Suggest suitable career fields based on their answers.
  • Show the skills required for each career.
  • Give a beginner-friendly learning roadmap.
  • List possible entry-level job roles.

How the Recommendations Work

Each answer in the assessment gives points to one or more career fields. When you submit the form, JavaScript adds up the points and the field with the highest score is shown first.

This website does not use artificial intelligence or machine learning. It only uses simple scoring written in JavaScript.

Important Note

The results are only guidance to help you start exploring. They do not guarantee that a career is right or wrong for you.

Technologies Used

  • HTML5 for the page structure
  • CSS3 for styling and responsive layout
  • Vanilla JavaScript for the questionnaire and scoring
  • Git and GitHub for sharing the code
